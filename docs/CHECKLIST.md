# Ручная проверка в MAX (прод)

То, что нельзя проверить автоматически: настоящий клиент MAX (мобильный и веб), вебхук, мини-приложение внутри MAX.
Всё остальное покрыто тестами и сквозным прогоном по API (`docs/REVIEW.md`, этап 15).
Отмечайте результат для **мобильного** и **веб**-клиента MAX.
