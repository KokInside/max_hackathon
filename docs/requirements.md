## 4. Критерии оценки онлайн-этапа (стр. 11–13)

Шкала по каждому критерию — 0–3 балла.

### 4.1. Продуктовая оценка — 40% онлайн-этапа

| ID | Критерий | Вес | Как закрываем |
|---|---|---|---|
| REQ-63 | Потенциал масштабирования | 35% | Правила и справочники вынесены в версионируемый конфиг; ядро не зависит от региона; порядок тиражирования «дом → УК → регион»; риски |
| REQ-64 | Пользовательская ценность | 25% | Узкий сегмент (председатель совета МКД); проблема по формуле ТЗ; сроки 10/30; интервью после сдачи — сейчас как аргументированные допущения |
| REQ-65 | UX/UI | 20% | Короткий путь в боте + чек-лист в мини-приложении; явные состояния загрузки, успеха и ошибки; нет тупиков (у каждого экрана есть «назад» и следующий шаг) |
| REQ-66 | Обоснованность и целостность | 15% | Цепочка «срок → проверка → доказательства → документ → отправка → новый акт»; каждое решение с обоснованием |
| REQ-67 | Качество презентации | 5% | 12–14 слайдов без перегруза, схемы читаемы |
